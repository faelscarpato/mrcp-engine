Política de Privacidade

Última atualização: 11 de setembro de 2026

1. Introdução

O MRCP Engine ("nós", "nosso") respeita a sua privacidade. Esta Política de Privacidade explica como tratamos as informações quando você utiliza nossa ferramenta e a nossa integração (MCP) com o Microsoft Copilot e outros agentes de Inteligência Artificial.

2. Coleta e Uso de Dados

O MRCP Engine opera fundamentalmente como uma ferramenta de análise estática de código (AST). Quando você utiliza nossos serviços:

  • Análise Local (MCP/CLI): Todo o processamento ocorre localmente na sua máquina. Não coletamos, armazenamos ou transmitimos o código-fonte, configurações locais ou dados pessoais para servidores externos.
  • Uso da API Web hospedada: Caso utilize nossos endpoints hospedados para analisar repositórios públicos, os dados fornecidos (como URLs de repositórios) são processados de forma efêmera em nossa infraestrutura. Não armazenamos o código analisado de forma permanente, utilizando-o estritamente no escopo da requisição para gerar o relatório de análise técnica e arquitetural devolvido ao Agente.

3. Compartilhamento de Informações

Não vendemos, trocamos ou transferimos informações para terceiros. O MRCP Engine, quando conectado ao Microsoft Copilot ou ferramentas similares, apenas atua respondendo às requisições do agente de IA com os dados de análise técnica solicitados.

4. Segurança

Adotamos medidas adequadas para garantir que o processamento (mesmo efêmero) das requisições na nossa infraestrutura seja seguro. Recomendamos que os usuários não utilizem a API pública para repositórios contendo dados sensíveis, chaves de acesso ou informações privadas que não devam ser trafegadas na internet.

5. Alterações nesta Política

Podemos atualizar esta Política de Privacidade periodicamente. As mudanças entrarão em vigor assim que publicadas nesta página.

6. Contato

Se tiver dúvidas sobre esta política, você pode abrir uma issue no nosso repositório oficial no GitHub.
