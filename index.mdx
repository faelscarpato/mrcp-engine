# Contexto estrutural para decisões melhores

O MRCP Engine analisa código e documentos para produzir sinais estruturados sobre arquitetura, saúde do código, segurança e contratos. Você pode consumi-lo pela API REST, por ferramentas MCP, pelo CLI ou pela extensão de IDE — cada caminho tem um comportamento diferente.

## Escolha o caminho certo

| Se você quer… | Comece por… | O que considerar |
| --- | --- | --- |
| Fazer uma chamada sem instalar nada | [API REST](/docs/reference/rest-api) | O serviço hospedado precisa conseguir acessar o repositório informado. |
| Dar ferramentas ao seu agente de código | [Integrações MCP](/docs/guides/integrations) | MCP remoto e MCP stdio são transportes diferentes; stdio não significa que toda ferramenta rode offline. |
| Inspecionar uma pasta privada sem enviá-la ao serviço hospedado | [CLI local](/getting-started#analisar-uma-pasta-local) | A análise local executa a suíte completa no computador e requer o core disponível. |
| Obter sinais no fluxo do editor | [Extensão VS Code](/docs/integrations/vscode) | A extensão analisa o workspace e oferece comandos e visualizações próprios. |

<Note>
Os relatórios descrevem o que cada etapa conseguiu medir. Verifique avisos, limitações e etapas indisponíveis antes de tratar uma pontuação como conclusão; uma etapa sem dados não equivale a resultado zero nem a aprovação.
</Note>
